## О проекте

**FinAPP** — мобильное игровое приложение под платформу Android (8.0+), формирующее базовые навыки управления личными финансами у детей в возрасте 7–11 лет через заботу о виртуальном питомце — котике Финни.

### Ключевые функциональные возможности:
- **Живой анимированный персонаж**: кот Финни реагирует на заботу, меняет эмоции (радостный, гордый, грустный, удивленный), растет по 3 стадиям (Малыш -> Юниор -> Мастер с золотой аурой) и кастомизируется:
  - **5 светящихся подиумов**: Изумрудный, Звёздный, Цветочный, Космический, Облачный;
  - **6 детальных рабочих столов**: IT-Финансист, Творческая мастерская, Лавка предпринимателя, Верстак инженера, Кабинет профессора, Эко-стол биолога (созданы по референсу Департамента финансов);
  - **35 комбинаций сцены** х 3 стадии роста = **105 визуальных вариаций** маскота;
  - **Персональное имя питомца** с автоматическим склонением и контекстными репликами.
- **Аппаратное автопроигрывание анимаций и озвучка**: при тапе по котику Финни издает чистое короткое мяуканье с тактильным виброоткликом, воспроизводится анимация и обновляется облачко с финансовым лайфхаком.
- **Интерактивный онбординг (11 шагов обучения)**: подробный обучающий мастер без сторонних эмодзи, с высокой контрастностью и динамическими индикаторами, знакомящий ребенка со всеми кнопками, шкалами и возможностями сервиса.
- **Планирование бюджета по правилу трех конвертов**: распределение доходов на *обязательные расходы*, *желания* и *накопления* с кастомной круговой диаграммой (`DonutChartDrawable`), контролем остатка и сравнением «План vs Факт».
- **Магазин заботы и сохранение покупок**:
  - Четкое разделение на регулярные расходники (еда, гигиена, витамины) и нерегулярные радости (игрушки, мебель).
  - Нерегулярные покупки сохраняются в инвентаре со статусом **«Куплено»** и блокируются от повтора до смены стадии роста (Малыш -> Юниор -> Мастер).
  - Высококонтрастная фиолетовая кнопка **«В цель»** (`ic_nav_goals.png`) для превращения любого товара в финансовую цель.
- **Взаимная синхронизация магазина и целей**: покупка предмета цели в магазине автоматически завершает финансовую цель, увеличивает счетчик достижений и предлагает выбрать следующую цель. На сбережения в копилке начисляется **+5% сложного банковского процента** при каждом переходе периода.
- **Аналитика и история периодов**: кастомный векторный график динамики (`HistoryChartDrawable`) со столбиками расходов и кривой накоплений с многоцветными маркерами (зеленый — обязательные, фиолетовый — желания, золотой — сбережения), дополненный карточками завершенных периодов.
- **Академия финансовой грамотности**: банк практических кейсов по 3 темам (бюджет, сбережения, кибербезопасность), основанный на стандартах Единой рамки компетенций Минфина РФ и Банка России. Двухколоночная модалка разбора с мудростью котика.
- **Финансовый словарь**: термины с понятными детскими метафорами из реальной жизни для двух возрастных групп (7–8 и 9–11 лет).
- **Кабинет родителя**: защищенный 4-значным PIN-кодом (с сенсорным пин-падом и резервной математической капчей) раздел с детальным **журналом освоения тем ребенком** (разбивка по 3 направлениям финансовой грамотности: бюджет, сбережения, безопасность со статусом и вознаграждением каждого решенного кейса), аналитикой прогресса, начислением поощрительных бонусов (+100 монет), управлением демо-режимом и кнопкой **«Сброс данных приложения»** с защитным подтверждением.
- **Презентационная графика и эргономика**: 100% отказ от стандартных эмодзи в пользу векторных иконок брендбука ЛЦТ 2026, строгий контроль контрастности элементов (WCAG AAA), сенсорные области не менее 48dp.

## Инструкция по запуску в Visual Studio 2022 (Debug / Release)

Для удобства разработчиков и членов жюри подготовлено пошаговое руководство с иллюстрациями настроек:
-> **[Полная визуальная инструкция по запуску в Visual Studio 2022](docs/VS_RUN_GUIDE.md)**

### Краткий порядок запуска:
1. Убедитесь, что в **Visual Studio Installer** установлена рабочая нагрузка **«Разработка с помощью .NET Multi-Platform App UI» (.NET MAUI)**.
2. В строке поиска Visual Studio (`Ctrl + Q`) найдите **«Android Device Manager...»** и создайте виртуальное устройство:
   - Базовое устройство: `Pixel 7 (+ Store)`
   - Процессор: `x86_64`
   - ОС: `Android 8.0 — API 26` (Google APIs: включено, RAM: 3072 МБ).
3. **Запуск в режиме DEBUG (отладка):**
   - Выберите конфигурацию **`Debug`** и устройство `Pixel 7 - API 26.0 (Android 8.0 — API 26)`.
   - Нажмите **`F5`** (запуск с отладчиком) или **`Ctrl + F5`** (быстрый запуск с XAML Hot Reload).
4. **Запуск в режиме RELEASE (релиз):**
   - Переключите конфигурацию на **`Release`** и нажмите **`Ctrl + F5`**.
5. **Быстрая сборка подписанного APK через PowerShell:**
   ```powershell
   pwsh -File .\scripts\build_apk.ps1
   ```
   Готовый файл: `dist/FinAPP.apk` (82.28 МБ, подписан ключом RSA 2048-bit `dist/finapp_release.keystore`, SHA-256: `95A4EDB20F08D1458F92F35F5C159E42192A30A7EFDDF9EE16AEF731355296D7`).
